# FEMA OCTO Virtual Technology Exchanges
Welcome to FEMA's Office of the Chief Technology Officer (OCTO) Technology Exchange repository!

This repository contains a folder for each of the OCTO Technology Exchanges. The exchanges are meant to leverage research ideas, scale innovations, and build cooperative collaboratios with private industry. The exchanges allow participants to provide white papers, suggestions, solution samples, demos, code, or other technological responses you wish FEMA to consider. Some exchanges are "reverse", where FEMA shares its concerns, issues, and technological requirements.
